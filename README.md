# the-lab-doctor
This project is for the Hack Club Cloudfall program. Welcome to the lab doctor, a Linux-based application and CLI (hopefully!) meant for sending jobs and receiving data on different pieces of hardware, including STM/Arduino microcontrollers, FPGAs, ESP32s, and HDDs! This will be amazing for home setups!

SSH will be the primarily communication protocol, but Telnet will still be present for **quick testing only**. Since the protocol sends data in plaintext, it is not secure and cannot be trusted with your sensitive data.
